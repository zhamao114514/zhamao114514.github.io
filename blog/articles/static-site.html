静态网站搭建心得

2026-08-30 · 技术

从零开始搭建一个纯静态博客，不需要服务器、不需要数据库，一个 HTML 文件就能跑起来。本文分享一下实现过程中的几个关键点。

一、开屏动画的实现

开屏动画使用 HTML5 的 <video> 标签实现，核心思路是：

  • 页面加载时显示一个全屏覆盖层（position: fixed; inset: 0; z-index: 9999）
  • 视频设置 autoplay muted playsinline，确保浏览器允许自动播放
  • 监听 ended 事件，播放完毕后给覆盖层加 opacity: 0 的过渡类
  • 过渡动画结束后移除视频节点，释放内存
注意：大多数浏览器禁止带声音的视频自动播放，所以开屏动画必须加 muted，否则视频不会播放，甚至可能被拦截后直接跳过。

二、自适应背景图

背景图要在不同屏幕尺寸下都不变形，核心 CSS 三件套：

  • background-size: cover — 等比缩放填满容器，超出部分裁切
  • background-position: center center — 以中心为基准裁切，保证主体不丢
  • background-repeat: no-repeat — 不重复平铺

再叠加一层暗色渐变遮罩（linear-gradient），让白色文字在任何背景图上都清晰可读。

三、文章页面的组织

所有文章放在 articles/ 文件夹下，每篇文章是一个独立的 HTML 文件。首页的文章卡片用 <a> 标签包裹，点击跳转到对应的文章页面。文章页面左上角放「返回首页」按钮，形成完整的浏览闭环。

四、为什么选纯静态

纯静态网站的优势很明显：

  • 零成本：GitHub Pages、Netlify、Vercel 都能免费托管
  • 极速：没有后端渲染，HTML 直接下发
  • 安全：没有数据库、没有登录，不存在注入风险
  • 简单：一个文本编辑器就能维护

对于个人博客来说，纯静态完全够用。后续如果需要搜索、评论等功能，可以再接入第三方服务（如 Algolia、Giscus），不需要改整体架构。
